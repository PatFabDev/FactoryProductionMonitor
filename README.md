# Factory Production Monitor

## Overview

Factory Production Monitor is a simple C# console application developed as a learning and portfolio project.

The application allows users to manage production records by creating, viewing, updating, and deleting entries. The project focuses on learning object-oriented programming, clean code, and CRUD operations before integrating a database.

## Features

* Add production records
* View all production records
* Update existing production records
* Delete production records

## Technologies

* C#
* .NET 10
* Object-Oriented Programming (OOP)

## Current Status

The application currently stores all production data in memory using `List<Production>`.

Database support with SQLite will be added in the next development stage.

## Learning Goals

This project is intended to practice:

* Object-oriented programming
* Working with classes and methods
* CRUD operations
* Clean code principles
* Git and GitHub workflow
* Database integration with SQLite (planned)
